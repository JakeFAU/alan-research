The loss certificate establishes an application before acknowledged owner death and withholding of a **successful authentic receipt** until the controller's post-death release. The context-aware barrier may exit with an error earlier. A runtime in-flight acknowledgment describes its emission point. The records do not measure continuous barrier occupancy, continuous transport liveness, or the relative emission order of the two acknowledgments. The two intermediate N07 cuts precede worker launch by synchronous source order. Final journals alone supply neither timing proposition.

Both raw archive byte streams match the sealed archive index. All 220 regular members of the four selected dossiers were compared against the indexed SHA-256, size and existing extraction. This includes 216 entries in the four case digest files and the four digest files themselves. Each of the 16 producer-side binding source hashes was checked for all four dossiers against the frozen Git blob and source manifest. `index.json` retains the case member prefixes and the hashes of the principal JSON and JSONL artifacts. Binary members were handled only as opaque hash bytes. No runtime execution or SQLite access was performed.

Archive membership anchors the genuine fixture outside its editable case directory. A freshly rehashed hostile dossier can still satisfy its internal digest list.
