Normal tar archives preserve their relative file trees. `checker-mutants.tar.gz` and `preliminary-apparatus.tar.gz` deduplicate unchanged bytes: read `files.json`, then copy each `sha256/<digest>` blob to its mapped original relative path. Their archive-format JSON sidecars record file/blob counts. Compiled test binaries are excluded; sources and exact build commands are retained. Existing Task1–Task4 archives remain untouched.

Raw SQLite evidence must never be opened in place. Extract and copy the database, WAL and SHM together into a disposable directory before SQLite or runtime Open inspection. The independent checker and this packaging process read JSON/file bytes without opening SQLite.

`source-after.json` records executable HEADs before later evidence-only commits. Actual command records, rather than the preparatory plan's proposed status, determine which gates ran. The initial full runtime promoted-parent skips were satisfied by explicit later normal/race runs. The historical opt-in baseline expected-failure test remains skipped and is not claimed as a final result. The full ordinary research suite additionally skips the opt-in Communication, Join and CandidateA artifact exporters; their exact test names/reasons are in the report and gate summary. Package no-test events are distinguished from optional tests. Global research lint is the exact inherited non-green baseline; changed checker lint is clean.

No artifact establishes unrestricted refinement, general completion, a public conflict-production schedule, a generation/revision-changing writer, or a performance theorem. Independent Task5 review and Task6 manuscript reconciliation are separate from this implementer's qualification.
